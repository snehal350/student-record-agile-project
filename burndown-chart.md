## Calculation
Ideal remaining work can be estimated as:

`Initial sprint points × (remaining sprint days ÷ total sprint days)`

Use the same agreed unit (story points) throughout. Actual remaining work should reflect the current status of the Sprint Backlog. A burndown chart is meaningful only when based on real updates.
