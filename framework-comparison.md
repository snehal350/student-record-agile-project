# Agile Framework Comparison

This comparison is a high-level summary for the Unit 2 assignment. Framework selection should depend on team size, coordination needs, and the institution's constraints.

| Framework | Main emphasis | Potential strengths | Considerations for this project |
|---|---|---|---|
| Scrum | Time-boxed sprints, defined accountabilities, review and adaptation | Clear goals and regular feedback | Suitable for a small student team with a defined deliverable |
| Kanban | Visualizing workflow and limiting work in progress | Flexible flow and visibility of bottlenecks | Useful for ongoing support or work arriving unpredictably |
| Extreme Programming (XP) | Engineering practices such as pair programming, continuous integration, and test-first development | Strong focus on code quality and rapid feedback | Helpful if the team is implementing software and can adopt the practices |
| Lean Development | Reduce waste, improve flow, learn continuously | Encourages focus on value and efficiency | Useful principles, but the team must define practical measures |
| Large-Scale Scrum (LeSS) | Applying Scrum across multiple teams working on one product | Coordination around a shared product | Likely excessive for a small classroom team |
| Scaled Agile Framework (SAFe) | Coordinating Agile work across larger organizations | Provides structures for large-scale planning | Too heavyweight for a small mini-project unless required by context |
| Scrum@Scale | Scaling Scrum through connected Scrum teams | Supports coordination across multiple teams | Unnecessary for one small team |

## Recommendation
For a small student team, Scrum is a reasonable starting choice because the assignment already requires epics, a prioritized backlog, sprint planning, Scrum ceremonies, and a Scrum board. Kanban can be used to visualize day-to-day work. XP practices can complement Scrum if software implementation is included.

This recommendation is based on the project's apparent classroom scale; it should be revisited if the team size or requirements change.
